## 🔗 Como executar

Na raiz do repositório, rode:

```bash
php -S localhost:8000
```

Depois acesse no navegador:

```text
http://localhost:8000/02_projetoPHP-02_refatorado/
```

Para preparar o banco da versão refatorada, execute o arquivo:

```text
02_projetoPHP-02_refatorado/sql/setup.sql
```
